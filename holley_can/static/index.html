HOLLEY USB-CAN CABLE & FIELD CHECKLIST
💡 NO RESISTORS NEEDED: If your Holley software already communicates with the Terminator X using this cable, your wiring, termination, and baud rate are already 100% correct. You do NOT need to install or measure any resistors.
1
Close Holley Terminator X Tuning Software:

Microsoft WinUSB allows exclusive hardware access by only one program at a time. If the official Holley software is open or online, close it before connecting Copilot.

2
Ignition Switch in RUN Position:

The Holley Terminator X ECU CAN transceiver only powers up when switched +12V is present in the "RUN" position. Accessory (ACC) is insufficient.

3
Enable CAN Broadcast in Holley EFI Calibration:

In Holley Terminator X Software, navigate to System Setup → CAN Devices and verify Enable CAN Broadcast (Racepak broadcast at 1 Mbps) is turned ON, then send tune to ECU.

4
Click [⚡ CONNECT] on Holley USB-CAN Cable:

In the detected adapters list above, locate Holley USB-CAN Cable (Part 558-443) and click the ⚡ Connect button to immediately bind and stream live telemetry.
